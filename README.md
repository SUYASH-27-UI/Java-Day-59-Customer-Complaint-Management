# Customer Complaint Management System – Java Day 59

## Description
A Java application to register, search, track and manage customer complaints.

## Features
- Register customer complaints
- View all complaints
- Search by complaint ID
- Update complaint status
- Generate complaint summary
- Store records permanently in a text file

## Technologies
- Java
- ArrayList
- File Handling
- Object-Oriented Programming

## Files
- `Main.java`
- `complaints.txt`

## How to Run
```bash
javac Main.java
java Main
```

## Concepts Used
Classes, Objects, Constructors, ArrayList, File Handling, Searching, Updating and Exception Handling.
